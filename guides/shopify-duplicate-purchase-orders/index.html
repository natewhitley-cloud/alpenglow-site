Duplicate and revised POs on Shopify: avoid entering an order twice

Updated October 28, 2026

Short answer: before you enter any PO, look for its number among your drafts and orders. Shopify doesn't list the PO number as a searchable order field, so tag every wholesale draft with its PO number (for example PO-4471) and filter by that tag. If you find a match, compare it line by line: identical means a resend you can ignore, changed means a revision to apply to the existing draft or order, never a second one.

Why the same PO arrives twice

Buyers resend a PO when they haven't heard back, forward it to a second address, or reply to their own email with a change. Their system may send a "revised" PO under the same number. In a shared inbox, two people can each enter the same email. Each of these looks like a new order unless you check, and a second draft that gets invoiced means a credit note and an awkward call.

Tell them apart

What arrivedHow to recognize itWhat to do
A resendSame PO number, same lines, quantities, dates and ship-toNothing in Shopify. Reply to confirm you have it.
A revisionSame PO number, but a line, quantity, price, date or address changedUpdate the existing draft or edit the order. Note what changed.
A cancellationSame PO number, marked cancelled or voidNote the cancellation, then delete the draft, or cancel the order if it's already one (restock items and refund any payment).
A new POA new PO number, even if the lines look familiarEnter it as a new order.
A reorder"Same as last time", often with changesDuplicate the last order, then apply the changes.

A revision that only changes the delivery date or ship-to is easy to miss: the lines match, so it looks like a resend. Compare the header (dates, address, terms) as well as the lines.

Make every PO findable

On a B2B draft order, the buyer's number goes in the PO number section. But Shopify's Help Center lists order number, customer name and product details as the fields you can search orders by, and doesn't mention the PO number. Try searching for the number; if it doesn't come up, the tag will. So add the PO number as a tag too:

  • Use one format, such as PO-4471. Tags on orders and draft orders can be up to 40 characters.
  • Filter by it. You can filter both the Orders and Drafts lists by tag, so the same tag finds the PO in either list.
  • Add it when you create the draft, not later. The point is to find it before you enter the next copy.

If two buyers could use the same PO number, they're still different orders. A match only counts as a duplicate when the company matches too.

Applying a revision

If it's still a draft

  1. Open it from the Drafts page and change the lines, quantities, dates or address to match the revised PO.
  2. Add a line to the note, such as "Revised per buyer email Oct 28: line 3 qty 24 to 36, ship date Nov 4".
  3. If you'd already sent the invoice, check the prices (invoices lock a draft's prices by default), then send the updated invoice so the buyer sees the revised total.

If it's already an order

  1. Edit the order: you can add or remove products, adjust quantities and update shipping fees.
  2. If the total goes up, send the buyer an updated invoice; on payment terms, the added amount is due with the rest of the order. If it goes down, issue a refund.
  3. If part of the order has already shipped, agree with the buyer what happens to the rest before you change anything.
  4. Note the change on the order, with the date of the revised PO.

Reorders: "same as last time"

Find the buyer's last order and duplicate it; Shopify can duplicate both orders and draft orders. Discounts and shipping rates aren't carried over, so add them again. Then apply the changes ("double the honey, drop the decaf"), check the company location and payment terms on the copy, and enter the new PO number. If the buyer doesn't give one, tag it so you can still find it.

In a shared inbox

  • Give each PO one owner: whoever opens it first labels or moves the email before they start.
  • Label the email as entered, with the draft or order number, once it's in Shopify.
  • Keep revisions in the same email thread as the original where you can, so the history is in one place.

Common questions

Can I search Shopify orders by PO number?

Shopify's Help Center lists order number, customer name and product details as the fields you can search orders by, and doesn't mention PO numbers. To be able to find an order by its PO, also add the PO number as a tag, such as PO-4471. Tags on orders and draft orders can be up to 40 characters, and you can filter both the Orders and Drafts lists by tag.

How do I change an order after the buyer sends a revised PO?

If it's still a draft, update it from the Drafts page. If it's already an order, edit the order: you can add or remove products, adjust quantities and update shipping fees. If the total goes up you can send the customer an updated invoice, and if it goes down you can issue a refund.

How do I repeat a wholesale customer's last order?

Duplicate the earlier order or draft order, then make the changes the buyer asked for. Discounts and shipping rates aren't carried over to the copy, so add them again, and enter the new PO number.
