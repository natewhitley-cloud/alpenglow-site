Does uninstalling a Shopify app remove its code from your theme?

Updated October 12, 2026

Short answer: not always. It depends on how the app put its code on your store. App blocks, app embeds and script tags stop loading when you uninstall. Code that an app wrote into your theme files, or that you pasted in while setting the app up, is not removed. It stays in your theme until you take it out. Shopify's own Help Center says the same: some apps add code to your theme that isn't automatically removed when you uninstall the app.

Two things the table can't tell you: whether a particular app used the old method or the new one, and whether it used both. Plenty of apps that now use app embeds started out editing theme files, and stores that installed them early can have both.

Why the answer changed over time

Shopify introduced theme app extensions (app blocks and app embeds) in 2021 so that apps would stop editing theme code. Every new app submitted to the Shopify App Store that works with your theme now has to use them. Apps that still leave code behind are required to give you instructions for removing it.

So leftover code mostly comes from apps installed years ago, apps that asked you to paste a snippet into your theme, and work done by a developer or agency on the app's behalf. Review widgets, popups, currency converters, upsell tools and page builders are common sources.

Script tags are on their way out as well. Since October 1, 2026 apps can't create or update them, and on March 1, 2027 Shopify stops adding them to storefronts.

How to check by hand

  1. List what you have uninstalled. In your Shopify admin, go to Settings → Apps and open the Uninstalled tab. It shows apps that were uninstalled from your store (Shopify describes these as recently uninstalled, so very old ones may be missing), and each app's page has a history of installs and uninstalls.
  2. Search your theme code. Go to Online Store, open the menu (…) on your theme and choose Edit code. Use the search button in the left sidebar, which searches every file in the theme, and look for each uninstalled app's name and its web address (for example appname.com). Matches in layout/theme.liquid, snippets, sections and assets are the usual finds.
  3. Look in the theme editor. Open your theme with Edit theme and check for Custom Liquid sections holding pasted app code. While you are there, open App embeds to see which embeds are switched on.
  4. Check Customer events. Go to Settings → Customer events → Custom pixels. A custom pixel is code that you or someone working on your store added, so it is not tied to the app's install. Check whether any of them belong to a service you no longer use.
  5. Watch what your storefront loads. Open your store in a desktop browser, open the developer tools (F12), choose the Network tab and reload. Requests to the web address of an app you no longer use mean something is still loading it.
  6. Repeat for other themes you plan to use. Each theme has its own files, so a theme you are about to publish needs the same search.

Found something? Don't delete it straight from your live theme. Deleted theme files can't be recovered, and removing a snippet file while another file still loads it causes an error on your storefront. Before you uninstall the next app

  • Check the app's App Store listing or ask the developer whether there are extra removal steps. Shopify's Help Center recommends this, and it is far easier while the developer still has you as a customer.
  • Switch off the app's embeds and remove its blocks in the theme editor if you want to see the storefront without it first.
  • Export anything you need. Some apps store data you can't get back after uninstalling.
  • Then uninstall: Settings → Apps, open the menu next to the app, choose Uninstall.

Common questions

Are app blocks and app embeds removed when I uninstall a Shopify app?

Yes, they stop loading. Shopify's developer documentation says that when a merchant uninstalls an app, the blocks associated with the app are automatically removed from online store themes. An entry for the app's embed can remain in the theme's settings file. With the app gone it should load nothing. App blocks and app embeds are the parts of an app you add or switch on in the theme editor.

Does Shopify remove an app's script tags when I uninstall it?

Yes. Script tags are scoped to the app that created them, and Shopify removes all of an app's script tags automatically when the app is uninstalled. Script tags are also being retired: Shopify stops adding them to storefronts on March 1, 2027.

What happens to an app's metafields after I uninstall it?

For metafields the app owns, Shopify removes the definitions (some straight away, some in a later cleanup) and keeps the values for a while before a background cleanup removes them. Shopify does not say how long that takes. Data an app stored outside its own reserved area is not covered by this and may stay. Metafields do not run code on your storefront.

Should I check for an app's code before or after I uninstall it?

Before, if you can. Shopify's Help Center recommends reviewing the app's App Store listing or contacting the developer before you uninstall, to find out whether extra removal steps are needed. If you already uninstalled, search your theme code for the app's name and web address.

Does an uninstalled app still have access to my store?

No. Uninstalling an app ends its API access to your store. That is also why an app cannot clean up its own theme code after you uninstall it. Code left in your theme can still load files from the app developer's servers in your shoppers' browsers until you remove it.
